# Legacy output index

These files were moved from `outputs/` without deleting their contents. They are retained as historical analyses and are not treated as current model artifacts.

| File | Contents |
|---|---|
| `results.json` | Earlier combined result bundle: forecast, benchmark forecast, backtest metrics and predictions, robustness, diagnostics, validity, quickscore, and metadata. |
| `diagnostics_annex.md` | Stationarity diagnostic notes, including ADF and KPSS results. |
| `robustness_annex.md` | Earlier robustness-analysis annex. |
| `mvp_alternative_specifications.json` | Diagnostic-only alternative specification metrics and out-of-sample prediction rows. |
| `mvp_backtest_predictions.csv` | Final-test actual classes, benchmark/model predictions, and class probabilities. |
| `mvp_classifier_runner.py` | Preserved previous Logistic Regression / Random Forest classifier pipeline and artifact generation code; superseded for the new ordered-logit specification. |
| `mvp_backtest_results.json` | MVP backtest split, parameters, metrics, class reports, confusion matrices, period comparisons, and limitations. |
| `mvp_detailed_error_analysis.csv` | Final-test prediction errors joined with observed factors, ranges, and out-of-range indicators. |
| `mvp_feature_distribution_comparison.csv` | Train/test descriptive statistics for each model feature. |
| `mvp_period_predictions.csv` | Chronological predictions and class probabilities for the evaluated test periods. |
| `mvp_prediction_collapse_diagnostic.md` | Narrative diagnostic of the models' repeated `Decrease` predictions. |
| `mvp_rf_final_test_probabilities.csv` | Random Forest final-test predictions and probabilities for the three decision classes. |
| `mvp_rf_range_error_analysis.csv` | Per-observation Random Forest correctness and predictor ranges relative to training data. |
| `mvp_rf_range_error_summary.json` | Aggregate class/error and out-of-range summaries for the Random Forest range analysis. |
| `mvp_structural_break_candidates.csv` | Candidate structural-break dates and associated test statistics. |
| `mvp_structural_break_summary.json` | Structural-break, stationarity, and source-availability diagnostic summary. |
| `week5_final_audit.md` | Hand-written Week 5 audit of the earlier classifier MVP (moved from `outputs/`); not generated by code and not a current result. |
| `mvp_validity_report.json` | Data, statistical, predictive, stability, structural-break, and alternative-specification validity results. |

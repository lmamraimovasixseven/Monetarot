# Аудит данных по рядам

Каждый ряд: покрытие, пропуски, ревизии, определение, смены классификации, календарные особенности. Числа посчитаны из файлов; известные свойства взяты из документов проекта (ссылки в тексте). Значения в data/raw никогда не меняются; флаги только помечают.

## `base_rate_history.csv`

- Покрытие: 2015-09 – 2026-10, 134 строк; пропущенных месяцев 0, дубликатов 0.
- Определение: Ставка после решения, вступившего в силу в этом месяце; строки до 2026-09 из таблицы prg.kz, 2026-10 со страницы НБ РК (docs/manual_steps_found.md).
- Источник: secondary: prg.kz (table); primary: National Bank of Kazakhstan, as cited in the table's own notes (NBK press releases); публикация UNKNOWN, получено 2026-10-08; ревизии после публикации: UNKNOWN.
- Смены классификации: UNKNOWN (в документах источника не проверялись).
- Календарные особенности: Решения вступают в силу в понедельник/вторник после объявления в пятницу; в 5 случаях объявление в предыдущем месяце (docs/model_spec.md, D20).
- Флаги экрана скачков: 0.
- События календаря вмешательств: 0.

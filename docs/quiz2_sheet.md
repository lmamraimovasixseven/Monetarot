# Шпаргалка к Quiz 2 (одна страница A4)

**Quiz 2 пишется индивидуально и без ИИ; этот лист нужно понять самой.** Здесь только определения и формулы, без чисел проекта.

## 1. Стационарность и разности
- Слабая стационарность: E[y_t] = μ, Var(y_t) = σ², Cov(y_t, y_{t−k}) зависит только от k.
- Первая разность Δy_t = y_t − y_{t−1}; сезонная Δ₁₂y_t = y_t − y_{t−12}; лог-рост 100·Δ ln y_t ≈ % изменение.
- ADF: H₀ единичный корень (нестационарен). KPSS: H₀ стационарен. Отвергли ADF и не отвергли KPSS → стационарен.
- Случайное блуждание y_t = y_{t−1} + ε_t: дисперсия растёт ∝ t; разность стационарна (I(1)).

## 2. Идентификация ARIMA(p, d, q)
- d — сколько раз брать разность до стационарности (не больше нужного: передифференцирование даёт MA-корень у 1).
- AR(p): ACF затухает, PACF обрывается после p. MA(q): ACF обрывается после q, PACF затухает.
- AR(1): y_t = c + ϕ y_{t−1} + ε_t, |ϕ| < 1; среднее μ = c/(1−ϕ); полураспад h = ln 0.5 / ln ϕ; прогноз ŷ_{t+h} = μ + ϕ^h (y_t − μ); дисперсия ошибки σ² Σ_{i<h} ϕ^{2i}.
- AICc = AIC + 2k(k+1)/(n−k−1), AIC = −2 ln L + 2k. Сравнивать только при одинаковом d и одинаковом ряде; |ΔAICc| ≤ 2 — ничья, берём проще.
- Ljung–Box Q = n(n+2) Σ_{k=1}^{m} r_k² /(n−k) ~ χ²(m − p − q): остатки должны быть белым шумом.
- SES: ℓ_t = α y_t + (1−α) ℓ_{t−1}; α → 1 ≈ naive.

## 3. Оценка прогнозов
- e = y − ŷ; MAE = mean|e|; RMSE = √mean(e²) (сильнее штрафует большие ошибки).
- Pinball для квантиля q: L = q(y − Q) при y ≥ Q, (1−q)(Q − y) при y < Q.
- Покрытие интервала = доля y внутри [L, U]; для 80% интервала ≈ 0.8. Мало — интервал узок, много — широк.
- Diebold–Mariano: d_t = L(e¹_t) − L(e²_t); DM = d̄ / √(V̂(d̄)); для h > 1 учитывать автокорреляцию до лага h−1; HLN-поправка для малых n.
- RPS (упорядоченные классы): (1/(K−1)) Σ_k (F_k − O_k)², F, O — накопленные прогнозные и фактические доли.
- Меньшая ошибка на одной выборке ≠ лучше: нужен интервал или тест.

## 4. Дизайн оценки
- Расширяющееся или скользящее окно; на каждом начале параметры переоцениваются только по прошлому.
- Бенчмарк: naive (ŷ_{t+h} = y_t); для сезонных рядов seasonal naive (ŷ_{t+h} = y_{t+h−12}).
- Кандидаты, горизонты и правило выбора замораживаются заранее (преререгистрация); число испытанных моделей записывается.
- Реальное время: использовать только данные, известные на дату прогноза (винтажи; без центрированных сглаживаний на конце).

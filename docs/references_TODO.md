# References: checklist for the student

The five reference slots are filled by `docs/references.md`. This file lists only what is still open. Do not add a citation here; add or change references only in `docs/references.md`, and only with sources you have read.

- [ ] **Claim-level check:** for every sentence in the note that cites a reference, confirm that the source supports that exact claim, and record the claim in the "Claim used in the note" column of `docs/references.md`.
- [ ] **Italics:** in the Word document, set journal titles and volume numbers in italics (APA 7).
- [ ] **Date of the existence and DOI check:** record when you checked them (currently UNKNOWN).
- [ ] **Method references:** if the note cites the HC0 sandwich covariance, the delta method, the Brant-type proportional-odds test or the Holm procedure, add a reference for each; until supplied they are UNKNOWN.
- [ ] **In-text citations:** every reference in `docs/references.md` is cited in the note, and every citation in the note appears in `docs/references.md`.

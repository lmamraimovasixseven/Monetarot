# Прогресс по брифу «The Decision Desk»

Порядок работ: Фаза 0 → A → B → F → D → E → C → G → I → H → J. После каждого блока: `python -m pytest -q -k "not check_01"`, `python run.py check`, обновление этого файла. Аудит до начала: `docs/brief_coverage.md`.

## Сделано

### Фаза 0 (2026-11-13)
- `docs/brief_coverage.md`: покрытие брифа по пунктам.

### Блок A: Decision memo
- `config/decision_losses.json` (потери — допущение пользователя), `src/decision_rule.py` (`python run.py decision`): порог p* = L_false/(L_false+L_miss), трёхисходные ожидаемые потери, чувствительность, оценка holdout потерями.
- `docs/decision_memo.md` (генерируется), `outputs/decision_rule.json`, поле `decision` в `model/artifact.json` (через `src/artifact_extensions.py`, без переоценки).
- Тесты: `tests/test_decision_rule.py`.
- Находка: на holdout средние потери модели, Always Hold и частот классов одинаковы (модель всегда выбирает «оставить»).

### Блок B: данные, журнал, аудит
- `ledger/evidence_ledger.csv` (`python run.py ledger`, `src/ledger.py`): каждое число отчёта, каждое число блоков артефакта, каждый ряд, файлы prereg; поле `evidence_ledger` в артефакте. Тест `tests/test_ledger.py`.
- Новые источники: `config/external_sources.json` (7 рядов, выбор 7-дневного обратного РЕПО НБК объяснён), шаблоны `data/raw/external/*.csv` (пустые: значения не из памяти), `src/external_data.py` (средневзвешенная ставка внутри месяца, курсы по рабочим дням, индекс ИПЦ → y/y, флаг Нового года по лунному календарю). Тест `tests/test_external_data.py`.
- `docs/DATA.md` (генерируется `src/data_doc.py`): аудит каждого ряда.
- `config/intervention_calendar.csv`: 4 записи (НДС 12%→16% с 2026-01-01, эпизод 2020, сдвиг уровня экспорта 2026-06, январский разрыв импорта).
- `src/vintages.py`: состояние «на дату t» по правилу публикации; тест: изменение после t не меняет результат на t.
- Append-only guard расширен на `data/raw/external/`.

### Блок F: преререгистрация и Reality Check
- `prereg/prereg.md`, `prereg/candidates.json` заморожены 2026-11-13 до написания модуля прогноза; `prereg/freeze.json` (хеши); `python run.py prereg` / `prereg-check` (`src/prereg.py`).
- Reality Check на 2026-12-04: ожидаемая ставка и 80% интервал из вероятностей модели и истории размеров шага; бенчмарк Always Hold; связь с существующей строкой `docs/forecast_log.csv` (не изменялась). Запасная цель: инфляция y/y за ноябрь (m/m в данных нет — отклонение от брифа, записано в prereg.md).
- `python run.py forecast-score` дополнительно считает RPS, pinball и попадание в 80% для Reality Check, когда решение появится в данных.
- `docs/model_card.md` (`src/model_card.py`, `python run.py model-card`): пределы и названный прошлый провал; те же факты пойдут в раздел «Пределы» сайта.
- `docs/redteam_response.md`: шаблон.
- Тесты: `tests/test_prereg.py`, `tests/test_model_card.py`.

### Блок D: модуль прогноза (D35)
- `src/forecast_desk.py`: `forecast(series, cutoff, h, method)`, 11 замороженных кандидатов, расширяющееся окно с переоценкой (первое начало после 60 наблюдений), h = 1, 2, 3, MAE/RMSE/pinball, покрытие формулой и квантилями прошлых ошибок (с выбором ближайшего к 80%), DM против бенчмарка, прогон без окон событий, ADF/KPSS, AICc только при одинаковом d с Ljung–Box и правилом ничьей, AR(1) с полураспадом по подпериодам из календаря вмешательств, y/y из m/m и «что нужно для X%» (функции; таблица UNKNOWN без ряда m/m).
- Результаты: `outputs/desk/forecast_desk.md`, `outputs/desk/backtest_*.csv`, блок `forecast_desk` в артефакте, журнал прогнозов `ledger/forecast_ledger.csv` (только добавление).
- `src/traps.py` (`python run.py traps`): шесть ловушек, падает при находке; тест с подложенной утечкой.
- Находки: инфляция y/y — ARIMA(1,1,0) и Holt с затуханием выигрывают у naive (DM p < 0.05); реальная ставка — нет выигрыша у naive; импорт — Holt-Winters выигрывает у seasonal naive на h = 1–2, на h = 3 нет; USD/KZT — данных нет.
- Тесты: `tests/test_forecast_desk.py`.

### Блок E: коридор carry trade
- `src/carry_corridor.py` (`python run.py corridor`): нижняя граница L = π_KZ + max(r_РФ, r_КНР) + премия; верхняя — минимум из потолка реального дифференциала и реальной ставки нулевого роста кредита (описательная МНК, используется только при отрицательном наклоне); положение и точка поломки; чувствительность к премии; регрессия изменения USD/KZT на реальный дифференциал (HC1, две спецификации, VIF, компас смещения, бенчмарк случайного блуждания) — запускается при наличии данных.
- `src/site_assets/corridor.js`: браузерный движок (ES3), сверка с Python до 1e-6 (node в CI, cscript на Windows).
- Найдена и исправлена ошибка выравнивания (pd.concat без сортировки перед shift): с исправлением наклон кредит/реальная ставка положительный, ограничение по кредиту не идентифицировано. Тест на упорядоченный полный индекс.
- Статус: реальных ставок РФ/КНР нет → коридор UNKNOWN до загрузки данных; параметры ползунков (премия 2, потолок 6) — допущение пользователя.
- `docs/instructor_notes.md`: пересказ требования, «из автоматической расшифровки, проверить».
- Тесты: `tests/test_carry_corridor.py`.

# Преререгистрация (заморожено 2026-11-13)

Этот файл и `prereg/candidates.json` заморожены до появления результатов, которые они описывают. `python run.py prereg-check` сверяет их хеши с `prereg/freeze.json` и падает, если файл изменён. Внешняя отметка времени: коммит на GitHub (его нужно сделать до 2026-12-04).

## 1. Цель прогноза (Reality Check)

- **Основная цель:** итог заседания НБ РК, объявленного на 2026-12-04 (дата объявления, `config/forecast_rounds.json`); результат — базовая ставка после решения (`data/raw/base_rate_history.csv`, месяц вступления решения в силу).
- **Модель:** замороженный ordered logit (`model/artifact.json`); вероятности уже записаны в `docs/forecast_log.csv` 2026-11-12 (строка с `target_decision_date` = 2026-12-04, её хеш артефакта). Эта запись не меняется.
- **Точка и интервал:** ожидаемая ставка = текущая ставка + сумма по исходам P(исход) × размер шага, где распределение размеров шага внутри «снижения» и «повышения» берётся из истории решений (`data/processed/nbk_decisions_clean.csv`); 80% интервал — 10-й и 90-й процентили этого дискретного распределения. Числа считает `python run.py prereg` и записывает в `model/artifact.json` (`reality_check`).
- **Бенчмарк:** Always Hold (ставка не меняется).
- **Оценка после решения:** RPS по трём исходам, pinball для квантилей 0.1, 0.5, 0.9 ставки, попадание факта в 80% интервал; разбор ошибки пишет человек. Команда: `python run.py forecast-score`.

Окно STL по ревизиям последней точки

Для каждого окна: средняя абсолютная ревизия сезонно скорректированного значения последней точки (оценка по данным до t против оценки по данным до t + 12), 24 последних начал. Выбирается окно с наименьшей ревизией; при равенстве — более короткое.

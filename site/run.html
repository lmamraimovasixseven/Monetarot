Запусти сам

Всё работает офлайн из закоммиченных данных на Windows и Linux (Python 3.13).

git clone https://github.com/lmamraimovasixseven/monetarot.git
cd monetarot
python -m pip install -r requirements-dev.txt
python run.py update      # данные → проверки → модель → прогнозы → журнал → site/
python run.py acceptance  # приёмные проверки
python run.py trace n:rmse_ratio

Одна команда для make: make update.

Сгенерировано python run.py site из model/artifact.json. Каждое число имеет строку в журнале доказательств.

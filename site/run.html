Run it yourself

Everything runs offline from the committed data on Windows and Linux (Python 3.13).

git clone https://github.com/lmamraimovasixseven/monetarot.git
cd monetarot
python -m pip install -r requirements-dev.txt
python run.py update      # data → checks → model → forecasts → ledger → site/
python run.py acceptance  # acceptance checks
python run.py trace n:rmse_ratio

The same as one make command: make update.

Generated by python run.py site from model/artifact.json. Every number has a row in the evidence ledger.
